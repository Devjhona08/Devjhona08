## `> Sobre mí`

Soy **Jhonatan**, desarrollador de software e ingeniero de ciberseguridad.

Me interesa comprender cómo funcionan los sistemas más allá de la superficie: su arquitectura, comportamiento, comunicación, seguridad y los pequeños detalles que terminan definiendo la calidad de un producto.

Disfruto convertir ideas en soluciones reales, experimentar con nuevas tecnologías y mejorar constantemente la forma en la que desarrollo software.

Mi perfil combina principalmente tres áreas:

```text

│   🛡️ Ciberseguridad                       │
│   ⚙️ Automatización                       │
│                                            │
╰────────────────────────────────────────────╯
```

## `> Mi forma de desarrollar`

```text
        IDEA
          │
          ▼
      CONSTRUIR
          │
          ▼
        PROBAR
          │
          ▼
       ANALIZAR
          │
          ▼
       MEJORAR
          │
          ▼
      OPTIMIZAR
          │
          ▼
        CREAR
```

Me gusta experimentar, probar escenarios reales, entender la causa de los problemas y mejorar una solución hasta convertirla en algo estable y útil.

No veo el desarrollo únicamente como escribir código.

Para mí también implica:

```text
Arquitectura
    +
Seguridad
    +
Rendimiento
    +
Experiencia
    +
Mantenibilidad
    +
Identidad
```
